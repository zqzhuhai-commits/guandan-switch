参考腾讯《大掼蛋》的休闲棋牌氛围，独立编写规则、AI 和界面；不含腾讯的程序、美术、角色、音频或账号服务。游戏完全离线，无内购、无联网、无真钱交易。

## 安装

1. 解压发行包，将 `switch` 文件夹合并到 SD 卡根目录。
2. 确认程序位于 `sdmc:/switch/GuandanSwitch/GuandanSwitch.nro`。
3. 在支持 homebrew 的 Switch 系统中，通过 hbmenu 启动“Guandan Time”。

中文字体内置在 NRO 中，无需另行下载资源。存档和设置写入相同目录的 `session.dat`、`profile.txt`。更新时保留这两个文件；可先备份整个目录。

这是 homebrew NRO，不是官方 eShop 游戏或可供原厂系统直接安装的 NSP。普通未配置 homebrew 的系统无法运行。当前已完成交叉编译、桌面画面检查和自动测试，尚未经过实体 Switch 验证；不将这些检查等同于真机兼容性验证。

## 四种模式

| 模式 | 内容 |
|---|---|
| 快速开局 | 每次进入随机发牌，完整单局，结算后可继续下一局 |
| 经典升级 | 双方从 2 打到 A，记录级别，自动完成进贡、还贡和抗贡 |
| 明牌练习 | 显示其余三家的全部手牌，便于练习配牌、拆牌与配合 |
| 定局挑战 | 固定种子的一组牌；回大厅重新进入可重试同一副首局，下一局进入后续题目 |

练习和挑战也计入本地胜率。本地数据仅作娱乐统计，不是竞技排名。

## Switch 操作

| 按键 | 功能 |
|---|---|
| 方向键 / 左摇杆 | 大厅选项、手牌光标 |
| A | 确认 / 选中或取消当前手牌 |
| X | 打出所选牌 |
| B | 清空选牌 / 关闭弹窗 / 结算返回大厅 |
| Y | 提示选牌，确认后按 X 出牌 |
| L | 不出；自由领出时不可不出 |
| R | 按点数重新理牌 |
| ZR | 开启或取消托管 |
| ZL | 查看本次运行期间的出牌记录 |
| + | 对局暂停；在大厅按 + 退出 |
| − | 玩法说明 |

支持触屏点按手牌和按钮。结算页按 A 进入下一局，按 B 返回大厅。暂停页可以保存后返回大厅。

## 功能

- 1280×720 逻辑画布，窗口/电视输出按比例缩放。
- 翡翠绿、深海蓝、午夜紫三种牌桌主题。
- 三档启发式 AI：休闲、标准、进阶；均只依据自身牌和公开的余牌数量决策。
- 三档 AI 出牌速度；基础操作音效可关闭。
- 逢人配标记、提示、全自动托管、手牌整理、余牌数量提示。
- 每次行动自动保存，可恢复未完成的牌局；战绩和偏好在本机保留。
- 余牌提示显示未打出的大小王和级牌总数，包含自己手牌；不是全点数记牌器。
- 托管中按 ZR 可重新接管。提示可能建议不出，按 L 执行。

## 本版规则口径

四人、两副完整扑克牌共 108 张，每家 27 张，对家组队。红桃级牌为配牌，可替代任意非王牌；单独打出及两张配牌作为对子打出时仍按级牌计算。

支持单张、对子、三张、三带二、固定五张顺子、固定三连对、固定二连三张（钢板）、四至十张同点炸弹、同花顺和四王炸弹。连续牌按自然点数计算，A 可作最低或最高，不能循环。

炸弹大小：四张 < 五张 < 同花顺 < 六张 < 七张 < 八张 < 九张 < 十张 < 四王。相同张数按点数比较，级牌高于 A。顺子和同花顺按最高自然点数比较。

同队获得头游、二游升 3 级；队友三游升 2 级；队友末游升 1 级。采用“打 A 且队友不是末游”过 A 的口径；必须在自己作为打 A 一方时获胜。未实现部分地方规则中的“三次不过 A 降级”或“以 A 结尾打回 2”。

升级赛自动进贡最高非配牌，自动还最低的非配牌，优先自然点数不高于 10；没有这类牌时还最低可用非配牌。单贡者持双大王或双贡方合计持双大王时抗贡。双贡中较大贡牌交给上局头游，由进较大贡牌者先出；同点时按上局名次固定决定。没有手动选还贡牌界面。

一轮中其他仍持牌者均连续不出后清桌；领出者已经出完时，由仍有手牌的队友接风。双下时不必打完其余两人的手牌，余下名次采用座次补齐，不影响双贡配对。

多种合法配牌解释由程序自动选择，优先可压住上一手的解释；自由领出时采用枚举中的合法解释。不提供手动指定配牌所代表点数的弹窗。

规则参考与差异校对：https://www.pagat.com/climbing/guan_dan.html 。本版明确采用上文的升级与还贡变体，不声称与腾讯版本或全部地区规则完全一致。

## 当前验证与限制

- `tests/rules.cpp` 覆盖牌型、双副牌花色、配牌、四王与十张炸弹比较、非法操作、接风、存档恢复和连续进贡升级流程。
- 四种模式共 256 局自动对局完成；具体输出见 `验证报告.txt`。
- 桌面运行同一份 SDL2 界面，检查大厅、牌桌、明牌模式、设置和规则弹窗；`preview` 目录为程序实际渲染，不是真机截图。
- Switch ARM64 NRO 已编译并检查文件结构；实体机上的启动、音频、触屏、休眠恢复和实际性能仍待验证。
- 进阶 AI 使用规则启发式策略，不是经过竞技训练的职业水平 AI。没有联网对战、本地多人、3D 角色、语音播报、背景音乐或残局编辑器。
- 当前出牌记录不随退出保存；牌局状态、级别、设置和本地战绩会保存。

## 源码与构建

仓库根目录包含规则引擎、SDL2 界面、测试、字体和 Makefile。发行 ZIP 中源码位于 `source-project`。

Switch 构建依赖 devkitPro 的 devkitA64、libnx、switch-sdl2、switch-sdl2_ttf、FreeType、HarfBuzz、zlib、libpng、bzip2。设置 `DEVKITPRO`、`DEVKITA64`，把 `portlibs/switch/bin` 和 `tools/bin` 加入 PATH 后，在工程目录执行 `make -j2`。

本次使用的开发环境镜像为：
`devkitpro/devkita64@sha256:82575ea78651b530b2e232bb3799cfd1fe331514e053d5f724bb4b28191fb79d`

桌面构建可用系统 SDL2/SDL2_ttf 开发包执行 `make -f Makefile.desktop`。测试：`g++ -std=c++17 -O2 tests/rules.cpp -o rules-test && ./rules-test`。
